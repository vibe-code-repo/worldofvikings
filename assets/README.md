# assets/

Binary game assets: models, textures, animations, audio, UI art. Served locally
by the development asset server on http://localhost:9000 (`pnpm dev:assets`) and
in production from `assets.world-of-vikings.com` (spec §37).

Third-party assets are vendored **unmodified**, in a folder named after the kit
they come from, with a `README.md` next to them carrying the full provenance
record — see `environment/kenney-retro-fantasy-kit/` and ADR-0012. A GLB that
references its texture by a relative path keeps the source layout, folder casing
included, so the committed bytes still match the download.

## placeholders/

Grey boxes standing in for the assets that live in the **private asset store**
outside this repository, because their redistribution rights are not settled
(ADR-0015). Each one carries the hull box and the root node name of the asset it
replaces, and is under 20 kB.

They are generated by `tooling/asset-pipeline/import-world-assets.ts` and
nevertheless committed — the one deliberate exception to "nothing generated is
committed", because their whole purpose is to exist in a clone that cannot run
the generator. A clone with no store loads these and says so on screen
(`assets: N private, M placeholder`).

Do not edit them by hand; re-run the import.

## manifest.json

`manifest.json` lists every file the game can download — the ones in this folder
**and** the ones in the store — with its size, SHA-256 hash, hull in metres and
full provenance (`origin`, `source`, `author`, `license`, `redistributable`,
`visibility`). It is what `pnpm validate:assets` checks, so an asset added,
replaced or deleted without updating it fails CI instead of turning into a 404 in
a player's browser (ADR-0011, ADR-0015). Refresh sizes and hashes with:

```bash
pnpm validate:assets --write
```

That never invents provenance: a file nobody has declared fails with a message.

The manifest itself, Markdown files and dot files (`.gitkeep`, `.DS_Store`) are
not listed — they are not downloaded by the game.

**Every contributed asset must document** source, author, license, usage rights
and whether it was modified — the manifest carries those as fields and rejects a
blank one; `docs/asset-licenses.md` is the per-set summary (spec §46). Assets
without redistribution rights and unknown-license files are
never merged **into this folder** — that is what the private store is for.

Formats: GLB for models, KTX2/PNG/WebP for textures, OGG for audio. Keep texture
sizes modest — browser performance is a requirement, not an afterthought (§38).
