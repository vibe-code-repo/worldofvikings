# Asset licenses

Every asset in `assets/` must be listed here before it is merged (spec §46).

| Asset path                             | Source | Author | License | Usage rights | Modified |
| -------------------------------------- | ------ | ------ | ------- | ------------ | -------- |
| _(none yet — Phase 0 ships no assets)_ |        |        |         |              |          |

## Rules

- No asset is merged without a row in this table.
- Never merge ripped game assets, unknown-license files, or anything that may not
  be redistributed.
- AI-generated assets: record the tool, the prompt source and any base inputs.
- Third-party assets keep their original license; add the license text or a link.

Source code is MIT (see `LICENSE`). Assets may carry a different license — the
license in this table always wins for the file it describes.
