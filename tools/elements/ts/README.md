# ts/ — TypeScript-Werkzeuge der Element-Werkbank

Noch leer. Hierher gehören die Werkzeuge aus Vorhaben 1 der Konzeptnotiz,
sobald sie entstehen:

| Geplant | Zweck |
|---|---|
| `hallen-generator-cli.ts` | Ruft `shared/src/hallenGeometrie.ts` von der Kommandozeile und druckt Quader-, Dreiecks- und Eckenzahl eines Saals. |
| `glb-schreiber-probe.ts` | Schreibt einen Saal mit `GlbSchreiber.ts` und hält das Ergebnis gegen das Blender-Erzeugnis. |

Der Ordner steht schon da, damit diese zwei beim Entstehen nicht wieder
irgendwo landen — genau das war der Grund für den ganzen Umzug.
